Seven weekly tasks — from a first React component to static and dynamic rendering and SEO. Each task lives on its own branch.

## 🪜 My tasks

| # | Branch | What I built |
|---|---|---|
| 1 | [`feat/franciszek-pora-1`](../../tree/feat/franciszek-pora-1) | A `ProjectCard` component in React + TypeScript |
| 2 | [`feat/franciszek-pora-pierwszy-projekt`](../../tree/feat/franciszek-pora-pierwszy-projekt) | My first **Next.js** project styled with **Tailwind** |
| 3 | [`feat/franciszek-pora-komponenty`](../../tree/feat/franciszek-pora-komponenty) | A `TeamMemberCard` with `next/image`, `next/link` and `next/font` |
